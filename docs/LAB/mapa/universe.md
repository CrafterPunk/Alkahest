## Resumen

- ApplyPhase and all cell physics run only in awake chunks (SimStepper.cs:314) while DiffuseTemperature runs on the whole grid (2164): a sleeping cell can sit past its meltsAt/boilsAt and transform only when woken -- any new process with per-tick resources must WakeChunk itself (rule R55, see 813, 934)

- Steam lifetime is 60 ticks (~2s) then it becomes Empty unless temp<=condensesAt: conducting steam over long geometry will lose mass; condensation also happens instantly via ApplyPhase (line 620) whenever a steam cell's own temp drops to raw 80..99, i.e. any cool-ish region collapses it to water immediately (no surface/wall condensation concept)

- aux byte is fully allocated per archetype (Liquid: bit0 flow + 7-bit combustion; Powder: combustion/Brasa; Organic: 0x80/0x40/0x04/0x03): a new per-cell state (wetness, sediment load) needs a new CellGrid array (must travel in SwapCells and be handled by SetCell/Transform) and is NOT networked (SimSync syncs mat only; temp not synced, AlkahestSim.cs:764-766)
- Determinism: all randomness must be XorShift.FromCell(tick,x,y,uniqueSalt); salts already used listed at SimStepper.cs:111-131 (choose >553 and grep); per-cell processes are sampled with (x+y+tick)&mask patterns; System.Random only inside Universe.Create; never UnityEngine.Random; scan order alternates by tick parity (265-279)

- Solid cohesion falls 1 cell/tick straight down only into Empty (SimStepper.cs:1295-1308): no lateral toppling, no rigid bodies, liquids hold solids up -- 'moving cohesive solid bodies' has no primitive; Prensa/Compacto only exist in Game (Prensa.cs gates by EsBaseEstado, Universe.cs:937-945)
